뇌 MRI 5질환 분석은 무엇을 하는가

뇌 MRI 2D 슬라이스 한 장을 받아, YOLO26s-Seg 모델로 5가지 질환의 병변 위치(bbox, 외곽선 polygon)와 model confidence score를 돌려줍니다. 의사 진단이 아닙니다.

결과는 교육·연구용 참고입니다. confidence는 모델 confidence score이며 질병 확률이 아닙니다. 응답에는 is_diagnosis: false와 면책 문구가 항상 들어 있습니다.

MRI 전용입니다. 뇌 CT(출혈·germinoma)와 주소, 모델, 패키지가 모두 따로입니다.

한 번 요청이 지나가는 순서

  1. 화면이 MRI 슬라이스 이미지를 POST /api/v1/analyze/brain-mri로 보냅니다.
  2. routers/brain_mri.py가 파일을 받고 크기를 확인합니다. 모델 계산은 없습니다.
  3. class/brain_mri/preprocess.py가 PNG·JPG·DICOM을 그레이스케일 3채널 이미지로 바꿉니다.
  4. class/brain_mri/segmentation.py가 처음 요청 때 가중치를 불러오고 추론합니다.
  5. class/brain_mri/localization.py가 외곽선을 색으로 칠한 overlay PNG를 만듭니다.
  6. schemas/brainMriSchemas.py 형식으로 응답합니다. 검출이 없으면 predictions는 빈 배열입니다.

routers/brain_mri.py

한 줄로
MRI 분석 주소 두 개를 열고 class/brain_mri를 호출합니다.
받는 것
image 파일 하나와 include_overlay(기본 true).
하는 일
크기 검사, 디코딩, 모델 로드 확인, 추론 호출, 응답 조립.
돌려주는 것
분석 응답, 또는 GET /api/v1/brain-mri/health의 로드 상태.
하지 않는 일
NAS 업로드, DB 저장, 판독문 생성은 하지 않습니다.
헷갈리기 쉬운 점
모델을 못 불러오면 이 주소만 503입니다. CT 분석과 관리자 화면은 그대로 동작합니다.

class/brain_mri/preprocess.py

한 줄로
업로드 바이트를 모델 입력 이미지로 바꿉니다.
받는 것
PNG, JPG, DICOM 바이트와 파일 이름.
하는 일
그레이스케일 한 장을 3채널로 복제합니다. DICOM은 학습 데이터처럼 0.5~99.5 백분위로 0~255 정규화합니다.
돌려주는 것
HxWx3 uint8 배열.
하지 않는 일
CT HU 윈도우를 쓰지 않습니다. 3D 볼륨 전체를 처리하지 않습니다.
헷갈리기 쉬운 점
다중 프레임 DICOM은 가운데 프레임 한 장만 씁니다.

class/brain_mri/segmentation.py

한 줄로
YOLO26s-Seg 모델을 불러와 한 장을 추론합니다.
받는 것
전처리된 이미지.
하는 일
첫 요청 때 가중치를 읽고, 클래스 순서가 학습 때와 같은지 확인한 뒤 추론합니다.
돌려주는 것
검출 목록. 각 항목은 class_id, disease, disease_ko, confidence, bbox, polygon입니다.
하지 않는 일
가중치를 내려받지 않습니다. 파일 경로는 환경 변수로만 받습니다.
헷갈리기 쉬운 점
좌표는 업로드한 이미지의 픽셀 기준입니다.

class/brain_mri/localization.py

한 줄로
검출 외곽선과 박스를 원본 위에 그립니다.
받는 것
원본 이미지와 검출 목록.
하는 일
polygon을 반투명으로 칠하고, bbox와 라벨을 그린 뒤 PNG base64로 만듭니다.
돌려주는 것
overlay_png_base64.
하지 않는 일
Grad-CAM을 쓰지 않습니다. 세그멘테이션 모델이 외곽선을 직접 줍니다.
헷갈리기 쉬운 점
검출이 없으면 원본과 같은 그림이 나옵니다.

class/brain_mri/constants.py

한 줄로
클래스 순서, 한국어 이름, 색, 면책 문구를 둡니다.
순서
0 vestibular_schwannoma, 1 glioma, 2 brain_metastasis, 3 ischemic_stroke, 4 multiple_sclerosis.
헷갈리기 쉬운 점
학습 때 순서와 같아야 합니다. 바꾸면 가중치 로드 때 오류로 막습니다.

class/brain_mri/config.py

한 줄로
MRI 분석 환경 변수를 읽습니다.
값
BRAIN_MRI_MODEL_PATH(가중치 경로), BRAIN_MRI_CONF_THRESHOLD(기본 0.25), BRAIN_MRI_MAX_UPLOAD_BYTES(기본 20MB).
하지 않는 일
루트 config.py의 DB·NAS 설정을 건드리지 않습니다.
헷갈리기 쉬운 점
가중치 파일은 저장소에 넣지 않습니다. 각자 PC 경로를 .env에 적습니다.

schemas/brainMriSchemas.py

한 줄로
MRI 응답 형식을 정합니다.
헷갈리기 쉬운 점
CT 응답(analyzeSchemas.py)은 분류 확률이고, MRI 응답은 검출 목록입니다. 둘을 섞지 않으려고 파일을 나눴습니다.

확인하는 법

  1. .env에 BRAIN_MRI_MODEL_PATH를 적고 서버를 켭니다.
  2. /docs에서 POST /api/v1/analyze/brain-mri에 MRI PNG를 올립니다.
  3. 200 응답과 predictions 배열을 확인합니다. 빈 배열도 정상입니다.
  4. pytest tests/test_brain_mri.py를 실행합니다. 가중치가 없으면 실제 추론 테스트는 건너뜁니다.
