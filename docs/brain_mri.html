뇌 MRI 5질환 분석은 무엇을 하는가

8-bit PNG/JPEG 뇌 MRI 2D slice 한 장을 받아, YOLO26s-Seg 모델로 5가지 질환의 병변 위치(bbox, 외곽선 polygon)와 model confidence score를 돌려줍니다. 의사 진단이 아닙니다.

결과는 교육·연구용 참고입니다. confidence는 모델 confidence score이며 질병 확률이 아닙니다. 응답에는 is_diagnosis: false와 면책 문구가 항상 들어 있습니다.

MRI 전용입니다. 뇌 CT(출혈·germinoma)와 주소, 모델, 패키지가 모두 따로입니다.

지원 전처리·sequence 가 확인된 2D MRI slice 에 대한 prototype inference입니다. 임의의 MRI 에서 5질환을 판별하는 범용 모델이 아닙니다.

모델 제한사항

통합 모델은 질환마다 다른 공개 데이터셋과 다른 sequence 로 만든 PNG 를 합쳐 학습했습니다. 한 질환 데이터에는 다른 질환이 라벨로 없습니다.

classsequence원본PNG 정규화
0 vestibular_schwannomaT1DICOM3D 볼륨 전체 0.5~99.5 백분위
1 gliomaT1CENIfTI3D 볼륨 전체 0.5~99.5 백분위
2 brain_metastasisT1CNIfTIslice 마다 0.5~99.5 백분위
3 ischemic_strokeDWINIfTIslice 마다 0.5~99.5 백분위
4 multiple_sclerosisFLAIRNIfTIslice 마다 1~99 백분위
  • 학습과 다른 sequence, 기관, 전처리의 영상은 결과를 신뢰할 수 없습니다. 예를 들어 FLAIR slice 에 나온 glioma 검출은 근거가 약합니다.
  • NIfTI 4질환은 배열 축 그대로 PNG 로 저장했습니다. 보통의 DICOM 뷰어 방향과 다를 수 있습니다.
  • 요청의 sequence(unknown, T1, T1CE, T1C, DWI, FLAIR, other)는 응답에 기록만 하고 추론을 바꾸지 않습니다.
  • 검출 0건은 병변이 없다는 뜻이 아닙니다.

한 번 요청이 지나가는 순서

  1. 화면이 8-bit PNG/JPEG MRI slice 를 POST /api/v1/analyze/brain-mri로 보냅니다. sequence는 선택입니다.
  2. routers/brain_mri.py가 파일을 받고 크기를 확인합니다. 모델 계산은 없습니다.
  3. class/brain_mri/preprocess.py가 PNG·JPEG 를 그레이스케일 3채널 이미지로 바꿉니다. DICOM 은 415 로 거절합니다.
  4. class/brain_mri/segmentation.py가 처음 요청 때 가중치를 불러오고 추론합니다.
  5. class/brain_mri/localization.py가 외곽선을 색으로 칠한 overlay PNG를 만듭니다.
  6. schemas/brainMriSchemas.py 형식으로 응답합니다. 검출이 없으면 predictions는 빈 배열입니다.

routers/brain_mri.py

한 줄로
MRI 분석 주소 두 개를 열고 class/brain_mri를 호출합니다.
받는 것
image 파일 하나와 include_overlay(기본 true).
하는 일
크기 검사, 디코딩, 모델 로드 확인, 추론 호출, 응답 조립.
돌려주는 것
분석 응답, 또는 GET /api/v1/brain-mri/health의 로드 상태.
하지 않는 일
NAS 업로드, DB 저장, 판독문 생성은 하지 않습니다.
헷갈리기 쉬운 점
모델을 못 불러오면 이 주소만 503입니다. CT 분석과 관리자 화면은 그대로 동작합니다.

class/brain_mri/preprocess.py

한 줄로
업로드 바이트를 모델 입력 이미지로 바꿉니다.
받는 것
8-bit PNG, JPEG 바이트와 파일 이름.
하는 일
그레이스케일 한 장을 3채널로 복제합니다. 값은 다시 정규화하지 않습니다. 학습 PNG 도 통합 단계에서 그대로 복사됐기 때문입니다.
돌려주는 것
HxWx3 uint8 배열.
하지 않는 일
DICOM 을 받지 않습니다(415). 16-bit·float 이미지를 받지 않습니다(400). CT HU 윈도우를 쓰지 않습니다.
헷갈리기 쉬운 점
DICOM 을 뺀 이유는 위 표처럼 질환마다 정규화 단위와 범위가 달라, slice 한 장으로 학습 PNG 를 똑같이 재현할 수 없기 때문입니다. PNG 는 학습 때 만든 방식으로 미리 변환한 slice 를 올립니다.

class/brain_mri/segmentation.py

한 줄로
YOLO26s-Seg 모델을 불러와 한 장을 추론합니다.
받는 것
전처리된 이미지.
하는 일
첫 요청 때 가중치를 읽고, 클래스 순서가 학습 때와 같은지 확인한 뒤 추론합니다.
돌려주는 것
검출 목록. 각 항목은 class_id, disease, disease_ko, confidence, bbox, polygon입니다.
하지 않는 일
가중치를 내려받지 않습니다. 파일 경로는 환경 변수로만 받습니다.
헷갈리기 쉬운 점
좌표는 업로드한 이미지의 픽셀 기준입니다.

schemas/brainMriSchemas.py

한 줄로
MRI 응답 형식을 정합니다.
헷갈리기 쉬운 점
CT 응답(analyzeSchemas.py)은 분류 확률이고, MRI 응답은 검출 목록입니다. 둘을 섞지 않으려고 파일을 나눴습니다.

확인하는 법

  1. .env에 BRAIN_MRI_MODEL_PATH를 적고 서버를 켭니다.
  2. /docs에서 POST /api/v1/analyze/brain-mri에 MRI PNG를 올립니다.
  3. 200 응답과 predictions 배열, limitations를 확인합니다. 빈 배열도 정상입니다. .dcm은 415 입니다.
  4. pytest tests/test_brain_mri.py를 실행합니다. 가중치가 없으면 실제 추론 테스트는 건너뜁니다.
