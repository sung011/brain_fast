학습 문서

기능을 코드로만 두지 않고, 각 부분이 무엇을 하는지 이 목록에서 읽습니다. 파일을 브라우저로 열면 됩니다.

  • 이미지 저장 — 스터디·팝업·채점 이미지와 분석 결과 파일을 네이버 클라우드 Object Storage 버킷에 올립니다.
  • 아이디·비밀번호 찾기 — 가입 정보 확인, 화면·API 연결, 해시 저장 흐름.
  • 뇌 CT 분석 — 화면 캡처를 받아 출혈·생식세포종양 가능성을 보고, 색으로 위치를 표시한 뒤 한국어 설명을 만듭니다.
  • 뇌 MRI 5질환 분석 — POST /api/v1/analyze/brain-mri. 8-bit PNG/JPEG MRI 2D slice에서 5가지 질환의 위치와 점수를 돌려줍니다. CT와 별개입니다.
  • 흉부 X-ray 분석 — 화면 캡처에서 흉부 소견 가능성과 위치를 표시하고, 흉부 문제의 ROI 채점에 씁니다. 팀 모델 연결 전에는 "모델 준비 중"을 돌려줍니다.
  • 흉부 모델 서버 설정 — .env에 THORAX_HF_REPO·THORAX_PACKAGES를 넣어 흉부 모델을 연결하고 확인하는 법.
  • 무릎 MRI 분석 — POST /api/v1/knee/screen-roi. 촬영면별 모델로 이상·ACL·반월판 가능성을 추정하고 ACL 위치를 표시합니다. 학습 채점은 POST /learning/roi-grade/knee입니다.
  • 회원가입 화면 — 이메일·비밀번호와 닉네임·생년월일·학교·전공 입력 안내. 학습자 저장은 POST /signup입니다. 이 저장소의 /signup HTML은 시연 화면입니다.
  • 학습 등록 — 관리자 /admin/study/create. X-ray·CT·MRI는 파일마다 문제(기본). 한 문제 슬라이드는 MRI만.
  • 팝업 — 관리자 등록 SSE와 학습자 GET /popups. 노출이면서 노출 기간 안인 팝업만 내려줍니다.
  • 학습 ROI 채점 — /learning/roi-grade. 단일 영상은 기존과 같고, MRI 슬라이드(JSON 배열)는 slice_index·image_path로 장을 고른 뒤 채점합니다. 흉부는 흉부 모델을 씁니다.
  • 오답노트 — 채점 기록 저장, 내 오답·부분정답 목록과 상세, 같은 문제 다시 풀기. 이미지 업로드가 실패해도 기록은 남습니다.
  • 오늘의 학습 현황 — GET /learning/today. 부위마다 학습 시간, 문제 수, 정답률.
  • 학습자 API 명세 — Vue 화면이 쓰는 로그인·계정 찾기·문제·ROI 채점·오답노트·흉부 분석 주소와 보내는 값·돌아오는 값·오류.
  • 의학용어 검색 — GET /glossary/search. 질문이 없으면 색인에서 3500건을 무작위로 고르고, 질문이 있으면 맞는 항목을 모두 돌려줍니다.
  • 복부 — 해당 class/ 패키지를 만들 때 같은 형식의 HTML을 여기에 추가합니다.
