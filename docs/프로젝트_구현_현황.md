# 프로젝트 구현 현황

로그인 후 부위와 영상 종류를 고르고, 영상 위에 영역을 그려 판독하면 정답·부분정답·오답이 나온다. 그 결과는 리뷰, 오답노트, 학습 기록으로 이어지고, 화면 분석도 같은 범위 안에서 동작한다.

점수를 만드는 연결은 끝나 있다. 앞으로 손볼 부분은 기능 추가가 아니라 뇌 CT, 흉부 X-ray, 뇌 MRI, 무릎 MRI 각 모델의 정확도다.

## MVP 범위 대비 구현 현황

### 완료

로그인, 홈, 학습 설정, 문제 풀이, 채점 리뷰, 오답노트, 학습 기록, 화면 분석이 한 흐름으로 동작한다.

다루는 영상은 뇌 CT, 뇌 MRI, 흉부 X-ray, 무릎 MRI다. 무릎은 전용 화면이 아니라 공통 풀이 화면(`/medical?region=knee&type=MRI`)에서 채점한다.

### 부분 구현

부위별 모델 정확도를 올리는 작업이다. 모델은 이미 풀이와 화면 분석에 연결되어 점수가 나온다.

| 부위 | 풀이 | 화면 분석 | 확인한 사례 | 남은 작업 |
|---|---|---|---|---|
| 뇌 CT | `POST /learning/roi-grade` | `POST /api/v1/analyze/screen-roi` | 문제 1번 두개내출혈, 정답 | 출혈·생식세포종양 점수 정확도 |
| 흉부 X-ray | `POST /learning/roi-grade` (서버가 흉부 모델로 처리) | `POST /api/v1/thorax/analyze/screen-roi` | 문제 101번 심비대, 부분정답 | 흉부 소견 점수 정확도 |
| 뇌 MRI | `POST /api/v1/analyze/brain-mri` | `POST /api/v1/analyze/brain-mri` | 문제 133번 전정신경초종이 가장 높음 | 5개 질환 분류 정확도 |
| 무릎 MRI | `POST /learning/roi-grade/knee` | `POST /api/v1/knee/screen-roi` | 9번째 장 가운데 박스 정답, 모서리 박스 오답, ACL 점수 0.916 | ACL 영역 겹침과 모델 점수 정확도 |

반월판은 시상면 모델이 없어 평가하지 않는 것이 정상이다.

### 미구현

| 항목 | 현재 |
|---|---|
| 복부 | 학습 설정에는 복부 CT·MRI가 있으나 등록된 문제가 없어 풀이로 이어지지 않는다 |
| 마이페이지 | 헤더에 메뉴만 있고 화면으로 이동하지 않는다 |
| 아이디·비밀번호 찾기 | 로그인 화면에 없다. `POST /find-id`, `POST /find-pw/verify`, `POST /find-pw`는 연결하지 않았다 |

## 핵심 기능 구현 수준

계획한 핵심 기능은 구현되어 서비스 목적을 달성할 수 있다.

학습자는 로그인 후 부위와 영상 종류를 고르고, 영상 위에 영역을 그려 판독한다. 채점은 정답·부분정답·오답을 내고, 그 결과는 리뷰, 오답노트, 학습 기록으로 이어진다.

부위마다 채점 주소가 연결되어 있다.

- 뇌 CT, 흉부 X-ray: `POST /learning/roi-grade`
- 뇌 MRI: `POST /api/v1/analyze/brain-mri`
- 무릎 MRI: `POST /learning/roi-grade/knee`

무릎은 공통 풀이 화면에서 포함률, ROI 정확도, ACL 모델 점수, 정답 박스를 보여 준다. 오답노트는 `GET /learning/reviews`로 오답·부분정답을 다시 푼다.

## 대표 시나리오 동작

대표 시나리오는 처음부터 끝까지 동작한다.

1. 로그인하면 홈에서 오늘 학습 현황이 나온다.
2. 학습에서 부위와 영상 종류를 고르면 풀이 화면이 열린다. 뇌 CT, 뇌 MRI, 흉부 X-ray, 무릎 MRI가 가능하다.
3. 영상 위에 박스를 그리고 판독하면 채점이 끝난다.
4. 리뷰에서 정답·부분정답·오답, 포함률, ROI 정확도, 정답 영역이 보인다.
5. 오답·부분정답은 오답노트에 남고, 다시 풀기로 같은 문제에 돌아온다. 전체 제출은 학습 기록에서 다시 연다.
6. 홈 카드와 상단 메뉴의 화면 분석을 누르면 `/analyze`로 이동한다. 화면을 공유하고 박스를 그리면 고른 모델이 점수를 준다.

| 화면 분석에서 고른 모델 | 주소 |
|---|---|
| 뇌 CT | `POST /api/v1/analyze/screen-roi` |
| 흉부 X-ray | `POST /api/v1/thorax/analyze/screen-roi` |
| 뇌 MRI | `POST /api/v1/analyze/brain-mri` |
| 무릎 MRI | `POST /api/v1/knee/screen-roi` |

무릎 MRI도 같은 시나리오다. 9번째 장에서 관절 가운데를 그리면 정답, 모서리만 그리면 오답이고, ACL 모델 점수가 함께 나온다.

## AI 기능 적용

프로젝트의 AI는 학습 풀이와 화면 분석 흐름 안에서 실제로 동작한다. 사용자가 영상 위에 영역을 그리면 부위별 모델이 점수를 만들고, 그 결과가 리뷰 화면에 나온다.

| 부위 | 하는 일 |
|---|---|
| 뇌 CT | 풀이는 `POST /learning/roi-grade`, 화면 분석은 `POST /api/v1/analyze/screen-roi`. 출혈과 생식세포종양 점수를 준다 |
| 흉부 X-ray | 풀이 `POST /learning/roi-grade`를 서버가 흉부 모델로 처리한다. 화면 분석은 `POST /api/v1/thorax/analyze/screen-roi`다 |
| 뇌 MRI | `POST /api/v1/analyze/brain-mri`로 5개 질환을 판독한다. 뇌 CT 출혈 모델은 쓰지 않는다 |
| 무릎 MRI | 풀이 `POST /learning/roi-grade/knee`가 ACL·반월판 점수와 정답 영역 겹침으로 정답·부분정답·오답을 만든다. 화면 분석은 `POST /api/v1/knee/screen-roi`다 |

홈과 상단의 화면 분석은 `/analyze`로 이어지고, 네 모델이 그 페이지에 연결되어 있다.

## AI 결과 검증

라벨이 있는 데이터로 모델을 만들어 학습 화면과 화면 분석에 연결했다. 영역을 그리면 점수와 정답·부분정답·오답이 나오는 것까지 확인했다. 그 점수가 맞는지 재는 검증은 하지 못했다.

의사를 통해 판독 결과를 대조하지도 못했다. 안심존에서 검증에 쓸 데이터를 찾아 보았으나, 팀이 원하는 데이터는 없었다.

지금 화면의 점수는 모델이 동작한다는 결과다. 정확도가 검증되었다는 뜻은 아니다. 각 모델의 정확도를 올리는 작업과 검증은 남아 있다.

## 주요 변경 사항 기록·정합성

기능 범위를 크게 바꾼 변경은 없었다. 로그인 후 부위와 영상 종류를 고르고, 영역을 그려 판독하면 리뷰·오답노트·학습 기록으로 이어지는 처음 설계를 유지했다. 화면 분석도 그 범위 안에 있다.

코드 정리는 공통 하네스(`AGENTS.md`)에 맞춰 했다.

- 화면은 기능 폴더에 둔다.
- HTTP는 `fetch`만 쓴다.
- 서버 주소는 `apiBase.js`, 로그인 세션은 `authSession.js`, 채점 저장은 `reviewModel.js`만 사용한다.
- 명세에 없는 화면과 라이브러리는 추가하지 않았다.

설계 문서와 화면이 같다. 완료 기준은 `docs/FEATURE_SPEC.md`이고, 동작 설명은 `docs/learn/index.html`이다.

## 이슈 대응·피드백 의사결정

큰 이슈는 중간 발표 때 나온 문제 말고는 없었다.

의학 용어 사전을 만들겠다고 했을 때, 멘토님이 Amazon Comprehend Medical, Amazon Transcribe Medical, AWS HealthScribe를 써서 만들어 보라고 했다. 세 서비스를 확인해 본 뒤 넣지 않기로 했다.

| 서비스 | 하는 일 |
|---|---|
| Amazon Comprehend Medical | 영어 임상 문장에서 질환·약·해부 표현을 뽑는 분석 |
| Amazon Transcribe Medical | 의료 대화를 글로 옮기는 음성 인식 |
| AWS HealthScribe | 진료 대화를 요약 |

팀이 만들려던 것은 학습 화면에서 부위·영상 종류에 맞는 용어를 보여주는 사전이다. 위 세 서비스는 그 기능이 아니라서 넣지 않았다. 자체 용어 목록을 `GET /glossary`로 받아 풀이 화면 오른쪽에 보여 준다.
