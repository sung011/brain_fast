복부 CT 장기 검출은 무엇을 하는가

화면 캡처(또는 DICOM) 복부 CT 절편 한 장을 받아, YOLO26m(kimsungil/abdomen_m1)으로 13개 장기의 박스와 점수를 돌리고, 뇌 CT와 같은 형식의 한국어 판독문(학습용)을 만듭니다.

결과는 교육·연구용 참고입니다. 질환 진단이 아니라 장기 위치를 표시합니다. 최종 판단은 의사에게 있습니다.

뇌 CT(출혈·germinoma)·흉부(X-ray)와 주소·패키지가 모두 따로입니다.

한 번 요청이 지나가는 순서

  1. 브라우저가 ROI 이미지를 POST /api/v1/abdomen/analyze/screen-roi로 보냅니다.
  2. routers/abdomen.py가 class/abdomen/을 불러 전처리 → 탐지 → overlay를 부릅니다.
  3. 응답 형식은 뇌 CT 분석과 같습니다. classification.task가 abdomen이고, 장기 점수는 그 장기 박스의 최고 신뢰도입니다.
  4. 판독문이 필요하면 POST /api/v1/abdomen/analyze/screen-roi/explain에 같은 이미지와 probs_json(13개)을 보냅니다.

검출 클래스 (13)

adrenal_gland, bladder, colon, duodenum, esophagus, gallbladder, kidney, liver, pancreatic, prostate, spleen, stomach, uterus

설정

가중치(best.pt)는 깃 저장소에 넣지 않습니다. 뇌 MRI와 같이 .env에만 경로·HF 저장소를 적습니다. 둘 다 비우면 복부 API만 503이고 다른 기능은 그대로입니다.

ABDOMEN_HF_REPO=kimsungil/abdomen_m1
ABDOMEN_HF_FILENAME=best.pt
ABDOMEN_CONF_THRESHOLD=0.15

학습 ROI 채점·저장

복부 문제(study.st_part=3)는 POST /learning/roi-grade에서 복부 YOLO로 채점합니다. 응답의 recall(포함률)·iou가 review_node.rn_recall·rn_iou에 저장됩니다. 예전에는 복부도 뇌 CT 모델로 떨어져 포함률이 비거나 잘못 나왔습니다.

GET /api/v1/abdomen/health로 로드 상태를 확인합니다. pytest tests/test_abdomen.py는 가짜 탐지기로 응답 형식·채점 저장 필드를 확인합니다.
