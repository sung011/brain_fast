학습 등록

관리자 화면 /admin/study/create에서 이미지를 네이버 클라우드 Object Storage에 올리고 study 행을 만듭니다. 결과는 학습용 보조이며 진단이 아닙니다.

파일마다 문제는 X-ray·CT·MRI 공통입니다. 한 문제의 슬라이드는 MRI만 선택합니다.

등록 방식

파일마다 문제 (upload_mode=each)
선택한 파일마다 study 1건. X-ray·CT는 이 방식만 있습니다. MRI도 기본값입니다.
한 문제의 슬라이드 (upload_mode=slide, MRI만)
여러 파일을 한 문제의 장으로 묶습니다. 파일 이름은 01_이름.png 형식이어야 하고, st_image에 JSON 배열로 저장됩니다.

파일마다 보기

templates/admin/study_create.html · assets/js/admin/study-create.js
한 줄: 등록 폼과 드래그 앤 드롭 UI.
받음: 부위·영상 종류·병명·파일 목록·등록 방식.
함: X-ray/CT면 슬라이드 선택지를 숨기고 each로 고정. MRI면 each/slide 선택. FormData로 POST /admin/study.
돌림: 성공·실패 목록을 화면에 표시.
안 함: Object Storage·DB 직접 접근.
헷갈림: 슬라이드 모드는 MRI + 파일 이름 앞 숫자 순서입니다.
